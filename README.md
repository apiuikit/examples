# APIUIKit examples

Real-world demos of [APIUIKit](https://apiuikit.com), the React component library for rendering OpenAPI and AsyncAPI documents. Each example is a self-contained app that shows APIUIKit inside an existing site, rather than as a standalone docs portal.

| Example | What it shows | Live |
| --- | --- | --- |
| [`swell-demo`](./swell-demo) | A fictional surf-forecast app whose developer guide mixes its own React components with `<OpenAPIEndpoint />` cards, plus full `<OpenAPI />` reference pages inside the site's layout. Built on the free [Open-Meteo](https://open-meteo.com) API. | [swell-demo.examples.apiuikit.com](https://swell-demo.examples.apiuikit.com) |

## Running an example

Each folder is an independent project with its own dependencies:

```bash
cd swell-demo
npm install
npm run dev
```
